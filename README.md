# In the Loop

An interactive 3D exhibit about a college student living with type 1 diabetes and using a hybrid closed-loop system. It shows a Tandem Mobi insulin pump, a Dexcom G6 continuous glucose monitor, and the wireless and physical paths that connect them.

## Run

Open `index.html` in a browser with WebGL support. All assets, including Three.js, are included. An internet connection is only needed to open the reference links.

## Explore

- Drag the model to rotate it. Scroll, pinch, or use the zoom buttons to inspect it. The focused model also supports arrow keys, +, −, and Home.
- Choose a numbered marker or the matching component in the inspector for an explanation.
- Open the pump and CGM cutaways to see internal components and a schematic skin section.
- In Campus life, choose a moment from Maya’s day. Green pulses represent CGM readings. Blue pulses represent insulin moving through the infusion tubing.

Maya is fictional. The hardware geometry and component positions are illustrative. This project contains no device-control or dosing software.
